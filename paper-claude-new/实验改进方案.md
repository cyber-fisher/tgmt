## P0-1 数据集升级(决定论文档次)

**问题:** 最大数据集 420 体素、500 树节点,与动机部分"流场可视化/科学计算/医学影像"的定位严重不符;§4.6 声称 GNN 优势在"大规模场景",却没有任何大规模实验。

**方案:** 三层数据集结构:

1. **合成受控集(已有):** 全部 20 个 case 都跑,主表报 mean±std,单 case 只做深入分析。把"3 个孤例"变成"20 个样本的统计结论"。
2. **公开标准体数据(新增,核心):** 从 Open SciVis Datasets 选 3–4 个,兼顾规模与拓扑复杂度:
   - `fuel` 64³ — 小,拓扑简单,入门验证
   - `neghip` 64³ — 分支多,适合展示多分支加权
   - `hydrogen_atom` 128³ — 中等规模
   - `bonsai` 256³ 或 `aneurism` 256³ — 展示可扩展性(可选,视运行时间)
3. **真实流场数据(可选加分项):** 若服务器可访问,加一个时变流场的单帧(如 Tangaroa 或 vortex street),直接呼应"流场可视化"动机。

**执行路径:**
- 树提取依赖 TTK,两条路:(a) 在服务器按现有《实验执行手册》流程跑 FTM 输出 tree_output.txt(流程已验证,只换输入);(b) 本地 `pip install topologytoolkit` 或 conda 装 TTK(若可行则完全本地化)。优先 (a),因为流程已跑通。
- 现有 C++/Python 简化器读 tree_output.txt + vti,输入格式不变,理论上直接适用;需验证 128³/256³ 下活性子图提取的内存与耗时(顺便产出 P2-2 的运行时间表)。

**风险:** 256³ 数据的增广轮廓树节点数可能达数十万,GNN 前向和 Jaccard 边集运算的耗时需先小规模测试;若过慢,128³ 封顶也足够(比现状大 3 个数量级)。

## P1-1 补充基线(证明"聪明的度量"胜过"傻办法")

**新增三个基线,全部实现成本低:**

| 基线 | 做法 | 回答的质疑 |
|------|------|-----------|
| Uniform | 沿标量值等距保留 k 个普通节点(k 对齐目标压缩率) | "均匀下采样不就够了吗?" |
| Random | 随机保留 k 个(固定种子,报 5 次均值) | 提供性能下界锚点 |
| Persistence | 按 Carr 2004 局部几何度量/TTK 持久性剪枝,保留至同压缩率 | "你引了 Carr 为最直接相关工作,为何不比?" |

三者都在"结构节点全保留 + 普通节点筛选"同一框架内实现,保证与本文方法可比。Uniform/Random 在 python_simplifier.py 里加两个 metric 分支即可;Persistence 用分支标量跨度作为节点重要性即可近似(与本文 w^topo 同源,正好构成"只用拓扑权重、不用几何度量"的消融)。

**预期表格:** 表 4 从 5 行扩到 8 行,ISM 不再是唯一外部参照。

## P1-2 中立评价指标(消除循环评价嫌疑)

**问题:** GeomErr^J 用 Jaccard 距离评估 Jaccard 方法自己筛的结果,GeomErr^G 同理——两张"自家考卷互换"仍是自家考卷。

**方案:** 增加两个与筛选准则完全独立的第三方指标:

1. **等值面网格 Hausdorff 距离(主推):** 对每个被删节点,用 VTK Marching Cubes 真实重建其等值面与最近保留节点的等值面,算对称 Hausdorff / Chamfer 距离(以网格对角线归一化)。这是几何学界公认的中立度量,VTK 本地即可实现(`vtkContourFilter` + `vtkDistancePolyDataFilter`)。
2. **属性曲线误差(轻量副指标):** 等值面面积 A(t)、体积 V(t) 随阈值的曲线,用保留节点做分段线性插值后与全节点曲线的 L2 误差。呼应已引用的 contour spectrum(Bajaj 1997),审稿人熟悉。
3. **(可选)ISM 的 NMI 作裁判:** 用 ISM 自己的距离场互信息评估本文结果——"用对手的尺子量,仍然赢"是最强的说服力。若本文方法在 NMI 下不占优,则不放正文,但自己要知道这个数。

**落点:** 表 4 每个数据集增加 Hausdorff 与 A(t) 曲线误差两列;结论若与 GeomErr 排序一致,"结论稳健"才真正成立。

## P1-3 GNN 鲁棒性实验(给 GNN 分支一个立足点)

**问题:** GNN 在两个数据集上全面输给 Jaccard,而 §3.3.3 宣称的"对平移和边增删更鲁棒"没有任何实验支撑——审稿人必然问"GNN 存在的意义"。

**方案:** 扰动稳定性实验,直接检验 §3.3.3 的声明:

1. **亚体素平移:** 对标量场做 0.1–1.0 个体素间距的三线性重采样平移,对同一(分支,阈值)分别算 Jaccard 距离与 GNN 余弦距离随平移量的变化曲线。预期:Jaccard 在 ~0.5 体素处急剧上升(边集大量替换),GNN 平缓——这正是论文声明的可视化证据。
2. **加性噪声:** σ ∈ {1%, 3%, 5%}×标量范围的高斯噪声,同上比较两种距离对"本应相同的等值面"给出的伪差异大小。
3. **分辨率变化(若做了 P0-1):** 同一标量场在 64³ 与 128³ 采样下,同一阈值的距离一致性。
4. **种子方差:** GNN 用 5 个不同 He 初始化种子,报告 GeomErr^G 的 std——堵住"随机网络不稳定"的质疑,一张小表即可。

**叙事升级:** 由此把 §4.6 的结论从"GNN 略差"改写为"规则小网格上 Jaccard 已足够精细;在数据扰动/重采样场景下 GNN 显著更稳定(图 X)",两种度量的适用边界从口头声明变为实验结论。

## P2-4 讨论与局限(§4.10 占位符)

实验全部完成后写,素材来自上述实验的"输的地方":
- multi 在低分支重叠数据上无增益(P0-2 的发现);
- GNN 在规则小网格上不如 Jaccard(P1-3 划定的适用边界);
- 极小分支(<3 节点)的权重鲁棒性;
- 极高压缩率(>80%)下的分布不均现象(用 ε=0.8 的分支保留率分布直接展示)。
