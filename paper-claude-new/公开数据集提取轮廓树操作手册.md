# 公开数据集提取增广轮廓树

## 目标

在装有 TTK 的服务器上，从 3 个公开 VTI 文件提取增广轮廓树，生成 `tree_output.txt`，拿回本地跑简化实验。

## 数据

已下载在 `experiments/data/public/`：

| 文件 | 维度 | 体素数 |
|------|------|--------|
| at.vti | 177×95×48 | 80 万 |
| viscousFingering.vti | 128³ | 210 万 |
| ctBones.vti | 256³ | 1680 万 |

## 输入

- `.vti` 文件（VTK ImageData 格式，含标量场）

## 输出

`tree_output.txt`，格式：

```
# Augmented Merge Tree (Only Tree Structure)
# 格式: [顶点编号] [父节点] [标量]
0 12 -0.0235857
1 70 0.36074
...
```

- 每行一个节点：`体素线性索引  父节点索引  标量值`
- 根节点的父节点指向自己
- 需要**增广**（保留所有普通节点，不只是关键节点）

## 服务器操作

```bash
conda install -c conda-forge topologytoolkit
python extract_contour_tree.py -i at.vti -o at_tree_output.txt
```

脚本核心逻辑：

```python
import topologytoolkit as ttk
ct = ttk.ttkMergeTree()
ct.SetInputData(image_data)
ct.SetTreeType(0)          # Merge Tree
ct.SetWithAugmentation(True)  # 增广：保留普通节点
ct.Update()
# 输出 port0=节点(VertexId, Scalar, CriticalType)
# 输出 port1=弧(upNodeId, downNodeId) → 构建父子关系
```

如果没有 conda 包，用 ParaView 的 `pvpython` 或 Docker (`topologytoolkit/ttk:latest`) 也行。

## 拿回本地后

有了 `tree_output.txt` + 原始 `.vti`，直接用现有脚本：

```bash
python experiments/scripts/python_simplifier.py \
    --tree at_tree_output.txt --vti at.vti \
    --metric jaccard --eps 0.05 --output out/at_jaccard
```

## 注意

- ctBones 需要 16GB+ 内存，预计 30-60 分钟
- 先拿 at.vti 验证格式正确再跑大的
- 本项目用的是 Merge Tree（TreeType=0），不是 Split Tree
