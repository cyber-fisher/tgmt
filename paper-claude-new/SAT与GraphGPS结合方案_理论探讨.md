# 基于 SAT 与 GraphGPS 的活性子图编码改进方案

**四个改造点概览**:

| 改造点 | 位置 | 现状 | 改造方案 | 成本 |
|---|---|---|---|---|
| C1 结构感知注意力 | 编码器 GPS Block 内部 | 注意力 Q/K/V 均取自节点表示 h | Q/K 取自 GINE 局部分支输出 | 小 |
| C2 边特征 λ | 编码器输入 | GINE 未使用边特征 | 输入等值面插值参数 λ | 小 |
| C3 树位置编码 | 编码器输入 | 4 维 SegmentationId sin/cos | 持久性/深度/弧内位置等树结构编码 | 中 |
| C4 树级注意力 | 多分支聚合 | 手工权重 w_ℓ(持久性+规模,α 混合) | 注意力权重替代 w_ℓ | 中 |

## 1. 框架视角:本方法与 SAT、GraphGPS 的关系

### 1.1 两个方法各自的角色

**GraphGPS 是编码器骨架,已经采用。** GraphGPS 的贡献是一个通用配方:每层由"局部消息传递(MPNN)+ 全局注意力"两条并行分支组成,输入端拼接位置/结构编码(PE)。当前实现即 3 层 GPS Block(局部分支 GINE、全局分支多头注意力)+ RWSE/LapPE,用于把一张活性子图编码为定长向量 z。

![Gemini_Generated_Image_f6hypaf6hypaf6hy](/Users/guoyichi.1/Downloads/Gemini_Generated_Image_f6hypaf6hypaf6hy.jpeg)

**SAT 提供的是注意力机制的改造原则与配套理论,尚未采用。** SAT 的核心主张:注意力中比较两个节点时,不应直接比较节点特征 κ(x_v, x_u),而应比较"以节点为中心提取的子图"的表示 κ(φ(v), φ(u)),其中 φ 称为结构提取器,用 GNN 实现,分两档——k-subtree(任意 GNN 运行 k 层取节点输出,表达力上限 1-WL)与 k-subgraph(对每个节点显式提取 k-hop 子图整体编码,表达力可超 1-WL,但需枚举全部子图,SAT 在 OGB 规模数据上因内存无法运行)。

![image-20260831200925475](/Users/guoyichi.1/Library/Application Support/typora-user-images/image-20260831200925475.png)

**两者的结合方式**:GraphGPS 提供层结构,SAT 提供"注意力的 Q/K 应取自何处"的原则。GPS Block 的 GINE 局部分支输出 h_local,恰好就是 SAT 定义的 k-subtree 结构提取器——即结合所需的全部组件已在当前架构中存在,只差把 GINE 输出接入注意力的 Q/K(改造点 C1)。这也是 SAT 论文自身的实验结论:结构感知注意力可以叠加在任意 GNN 之上并系统性提升其性能。

### 1.2 本框架与 SAT 的对应关系:哪些已成立,哪些待改造

以 SAT 的语言审视本框架,"比较子图表示而非节点特征"这一模式出现在两个层面:

| SAT 概念 | 网格层(编码器内部) | 轮廓树层(度量与聚合) |
|---|---|---|
| 节点 | 活性顶点 p【已有】 | 轮廓树候选节点 v_i【已有】 |
| 节点的结构子图 | p 的 k-hop 邻域【已有,GINE 感受野】 | 活性子图本身【已有】 |
| 结构提取器 φ | GINE 的 k 层消息传递【已有,但未接入注意力 → C1】 | 整个 GraphGPS 编码器【已有】 |
| 核比较 κ | 注意力权重【未实现 → C1】 | 分支差异 d_ℓ = 1 − cos(z(v_r), z(v_i))【已有】 |
| 核值加权聚合 | —— | 手工权重 w_ℓ,非注意力【未实现 → C4】 |

**已天然成立的部分(无需修改代码)**:轮廓树层的三件套——"轮廓树节点 v_i → 提取活性子图 → GraphGPS 编码读出 z → 余弦距离 d_ℓ"——恰好构成 SAT 的"结构子图 → 提取器 φ → 核比较 κ"。轮廓树节点本身仅携带一个标量 f(v_i),其几何含义完全由"该阈值下等值面穿过网格的方式"承载,这正是 SAT"节点的表示应由其子图给出"的思想。**论文可以立即用这套语言重新表述已有方法,属于叙事层面的收益,不依赖任何改造。**

**待改造的部分**:① 网格层的 GINE 输出未接入注意力 Q/K,当前编码器只是标准 GraphGPS 而非 SAT(→ C1);② 轮廓树层的多分支聚合采用手工权重而非注意力加权(→ C4)。

### 1.3 与 SAT 的关键区别:子图的来源(本文的贡献点)

| | SAT 的 k-hop 子图 | 本文的活性子图 |
|---|---|---|
| 子图的索引方式 | 图上局部性:从节点走 k 跳,纯组合规则 | **函数值**:阈值 t=f(v_i) 的水平集,与图上跳数无关 |
| 节点与子图所在的图 | 同一张图 | 节点在轮廓树上,子图在网格上,**跨域**对应 |
| 被比较子图的可比性保证 | 无,相邻节点的子图仅有重叠关系 | 亏格不变区间保证同分支内两张活性子图**拓扑同胚,差异纯几何** |

因此本文的合理定位是"**拓扑引导的子图提取**":由轮廓树决定用哪张子图代表节点,而非 k-hop 这类与任务无关的规则。SAT 对被比较的两张子图不提供任何拓扑保证,本文有 §3.2 的理论保证——这是实质性区别,论文表述时应避免写成"沿用 SAT 的提取器"。

### 1.4 SAT 的理论结果直接适用于现状

SAT 定理 1/2 对 φ 的唯一要求是有界;本文读出向量经 L2 归一化,天然满足。因此**对已实现的轮廓树层核比较,定理直接适用**:

- **定理 1(可控性)**:子图表示相似 ⇒ 输出相近,距离有显式上界,且对任意参数成立、无需训练。这正是简化度量所需的稳定性。§3.3.3 当前仅有"随机特征映射保证单射"的论证——单射只保证"不同的可区分",不保证"相似的靠得近",定理 1 恰好补上后者。
- **定理 2(判别力下界)**:输出的判别力不低于结构提取器。推论"提取器越强,度量越强"——解释了 GraphGPS(GINE)实验全面超过 2 层 GCN 的结果,也支撑 C4 树级注意力的论证。

### 1.5 一个 SAT 不具备、本文尚未利用的优势

v_r 与 v_i 的两张活性子图均为**同一网格 Ω 的子图**,顶点存在天然对应关系——SAT 处理的是两张完全不同的图,不具备此条件。Jaccard 度量利用的正是这一对应;而当前 GNN 采用余弦距离,顶点对齐信息完全丢失。这是一个待利用的空位,GLASS 的标注技巧、GMN 的跨图注意力、FGW 的最优传输对齐均可填补(§3)。

## 2. 四个改造点

### C1:注意力 Q/K 改为取自 GINE 输出(核心改造)

```
现状:  h_attn = MultiHeadAttn(h)                  # Q,K,V 均取自 h
改造:  h_attn = MultiHeadAttn(Q=K=h_local, V=h)   # h_local 为 GINE 输出
```

SAT 批评的正是现状:Q/K 取自节点特征,注意力仅对"特征+PE 相似"敏感,对"局部结构相似"不敏感。改造后的直观效果:等值面上两块局部形状相似的区域(如曲率相近的两个凸起)相互加强,而非两个恰好特征值相近的顶点相互加强。

**对坍缩问题的意义**:坍缩表现为不同分支的子图被映射到几乎同一方向(Val Pos Sim 0.9928)。结构感知 Q/K 在**架构层面**注入"结构不同 ⇒ 表示应不同"的归纳偏置,从源头抑制坍缩;对比学习损失只能在事后惩罚,归纳偏置更根本。

**本场景的额外便利**:SAT 表达力更强的 k-subgraph 档在大规模图上内存开销过大(其自认的主要局限),但活性子图仅几十至几百顶点(当前最大网格 12×8×5),无此瓶颈,可直接采用最强配置。SAT 消融显示 k≈3 最优,当前 3 层 GPS 恰对应 3-hop 感受野,超参数无需调整。

### C2:边特征 λ 输入 GINE

每条活性边 (p,q) 携带一个现成的几何量——等值面穿过该边的插值位置:λ = (t − f(p)) / (f(q) − f(p)) ∈ (0,1)。阈值微变时 λ 连续滑动。**Jaccard 仅判断边的存在性,λ 是其原理上不可见的信息**——这是"学习式度量凭什么超过 Jaccard"的信息增量来源之一。GINE 与 GCN 的核心区别即支持边特征,当前选用 GINE 却未输入任何边特征,浪费了架构能力。

### C3:树位置编码替代 SegmentationId 编码

现有 4 维 SegmentationId sin/cos 编码较粗糙:sin/cos 仅将分段 ID 映射为连续数,ID 相邻不代表树上相邻。改造为树位置编码,每个活性顶点 p 拼接:

| 分量 | 定义 | 含义 |
|---|---|---|
| 分支持久性 | π_ℓ/π_max(归一化) | 所在拓扑特征的显著性 |
| 分支深度 | 所属弧在分支分解中的层级 | 主干或细枝 |
| 弧内相对位置 | (f(p)−f_low)/(f_high−f_low) | 顶点在所属弧标量区间内的位置 |
| (可选)亏格区间 | 所处区间的 (c,g) | 与 §3.2 理论直接衔接 |

**主要收益在 multi 场景**:等值面存在多个连通分量时,不同分量的顶点获得不同的树编码,编码器得以感知"该等值面由哪几条拓扑分支贡献"。当前编码器对此完全不可见,这是 multi 配置"分支间差异被压缩到同一量级"的信息缺口之一。

**论文叙事**:可借用 SAT §4.3"结构编码与绝对编码互补"的论证框架——图内 PE(RWSE/LapPE,等值面内蕴坐标)、树 PE(标量场拓扑中的坐标)、结构感知注意力(局部结构相似性本身),三者正交,各司其职。

### C4:多分支聚合改为树级注意力

**现状**:w_ℓ 由(持久性, 规模)经混合系数 α 线性组合(式 wmix),聚合为 D = Σ w_ℓ d_ℓ(式 aggregate)。注意:核比较部分(z 的余弦距离)已有且天然符合 SAT 形式(§1.2),待改造的仅是加权聚合部分。

**改造**:token = 活跃分支 b_ℓ,其表示由第一层读出的 z_ℓ(v) 拼接树侧标量(π_ℓ、s_ℓ、|B(t_i)|、亏格区间)构成。以 v_r 的表示为 query、各活跃分支的表示为 key,**注意力权重直接替代 w_ℓ**,混合系数 α 被吸收。

**改造依据**:
- **针对 case17 multi 退化**:此前诊断的因果链为"embedding 空间过紧 → 分支间差异被压缩到同一量级 → 权重稀释 → 选点质量下降"。手工权重不依赖 embedding,对坍缩无法响应;注意力权重由表示计算得出,分支区分度直接进入权重通道,并可叠加 C1 的判别性偏置。
- **理论依据**:由定理 2,树级注意力输出的判别力不低于第一层编码器——"multi 不应劣于 single"在此架构下有理论支撑。当前实验中 multi 频繁劣于 single,恰说明短板在手工加权,而非多分支思想本身。

**训练信号分两阶段**:
1. **阶段一(不训练)**:Q/K 投影随机初始化,由定理 1"对任意参数成立"提供理论背书,零新增可训练参数(当前仅 6382 对训练样本,此点关键)。仅验证:结构感知权重相对手工 w_ℓ 是否有增益;
2. **阶段二**:确认增益后,将该层接入对比学习梯度,端到端训练。

## 3. 调研:GNN 之外的子图表示方法

活性子图具有三个特殊性:**规模小**(几十至几百顶点)、**携带连续几何属性**(坐标、标量值、λ)、**本质是嵌入 R³ 的离散曲面**。据此筛选了四条 GNN 之外的路线。

### 3.1 FGW 最优传输距离——语义上最契合,建议优先尝试

[Fused Gromov-Wasserstein](https://arxiv.org/abs/1805.09114)(Vayer et al., 2019):将两张图视为"带特征的度量空间",同时比较节点特征(Wasserstein 部分)与结构关系(Gromov-Wasserstein 部分),通过求解软匹配得到距离。无需训练,是真度量,且蕴含节点对齐。[LinearFGW](https://arxiv.org/abs/2203.04711) 可线性化为显式嵌入。POT 库有现成实现。

**与本文的关系**:本文要度量的正是"同胚等值面之间的纯几何差异",FGW 直接在"顶点坐标+连接结构"上计算最优匹配代价,无需先压缩为向量再取余弦;且天然给出顶点对应——§1.5 所述"同网格顶点对应被余弦丢弃"的问题,FGW 是正面解决。

**两种用法**:(a) 作为第三个度量,与 Jaccard、GNN 并列进入横向对比表——零训练、真度量、带对齐;(b) 作为 GNN 的训练监督:令 embedding 距离拟合 FGW 距离(类似 GREED 拟合 GED),每对样本提供一个连续监督值,信号密度远高于二值正/负例,可直接缓解 6382 对样本的瓶颈。计算代价高于余弦,但子图规模小,可以承受。

### 3.2 NetLSD 谱描述子——零训练的图结构签名

[NetLSD](https://arxiv.org/abs/1805.10712)(KDD 2018):计算 Laplacian 热核迹 h(t) = tr(e^{-tL}),多尺度采样得到一条签名曲线,图的比较即曲线的比较。其思想源头[热核签名 HKS](https://en.wikipedia.org/wiki/Heat_kernel_signature) 本为曲面分析设计——活性子图恰是等值面的离散化,以热核刻画其形状在物理上非常自然。`netlsd` 包一行代码可用。

**局限**:纯结构方法,不使用节点特征——坐标、标量值、λ 均无法利用,在"同胚等值面间比较几何"的分支内部场景大概率表现不佳。但这恰好构成反向论据:若其表现差,即证明"特征感知的度量有必要"。作为零训练基线,横向对比表中值得保留一行。

### 3.3 WWL 图核——小数据与连续属性场景的经典方案

[WWL(Wasserstein Weisfeiler-Lehman)](https://arxiv.org/abs/1906.01277)(NeurIPS 2019):以 WL 式迭代聚合邻域的连续特征,再对两图的节点特征分布计算 Wasserstein 距离。无参数,`wwl` 包有现成实现。

WWL 几乎是"无参数版的本文 GNN":WL 迭代对应 GCN 层,区别仅在不学习权重、比较分布而非池化向量。**"6382 对样本训练 187k 参数"的瓶颈在图核方法中不存在。** 若被问及"数据规模如此小,为何使用深度学习",WWL 是必须首先超过的对手:GNN 无法胜过 WWL,则诚实结论应为"小数据场景下无参数方法已足够"。

### 3.4 持久性图像——与轮廓树同源,需谨慎使用

[Persistence Images](https://arxiv.org/abs/1507.06217)(JMLR 2017):将持久性图转化为固定长度向量,具有稳定性定理。对每张活性子图以 f 为过滤函数计算 PD 再转为 PI,可得多尺度拓扑-几何摘要。

**需注意**:分支内部活性子图**拓扑已同胚**(§3.2 保证),而 PD 的主要信息恰是拓扑事件——同胚曲面之间 PD 差异有限。因此 PI 仅适合作为 readout 的特征补充(用于分支间比较,即 multi 场景),不能替代编码器。论文中还需说明其与本文方法的分工:轮廓树刻画全场拓扑骨架,PI 提供单张等值面内部的几何摘要,二者不重复。

### 3.5 决策表

| 路线 | 训练 | 连续特征 | 真度量 | 顶点对齐 | 定位 |
|---|---|---|---|---|---|
| GNN/GPS/SAT(§1-2) | 需要 | ✓ | ✗(余弦) | ✗ | 主方法,可端到端 |
| FGW | 不需 | ✓ | ✓ | **✓** | 第三度量 + 训练监督,**建议优先尝试** |
| NetLSD | 不需 | ✗ | 伪度量 | ✗ | 零训练谱基线,论证"特征的必要性" |
| WWL 图核 | 不需 | ✓ | 核诱导 | ✗ | 无参数对照,论证"学习的必要性" |
| 持久性图像 | 不需 | 部分 | 稳定非度量 | ✗ | readout 特征补充,multi 场景 |

FGW 优先的理由:唯一同时满足"真度量+顶点对齐+利用特征"的方案,正面补齐"余弦非度量"与"顶点对齐丢失"(§1.5)两个理论缺口;零训练,与数据瓶颈无关;若效果良好,还可作为 GNN 的蒸馏目标。NetLSD、WWL 接入成本极低(各一行代码),建议直接加入横向对比表。PI 优先级最低,待树 PE(C3)完成后再评估。
